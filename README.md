# GTA VII // Rio de Janeiro

Protótipo jogável em Three.js de uma cidade costeira inspirada no Rio de Janeiro. A cena é construída com geometria procedural e roda sem assets locais.

## Rodar

Instale Node.js 18+ e, na raiz do projeto, execute:

```bash
npm install
npm run dev
```

Abra a URL mostrada pelo Vite. Também é possível abrir `index.html` diretamente em um navegador moderno com acesso à internet, pois o Three.js é carregado por CDN.

## Controles

- `WASD` ou setas: mover
- `Shift`: correr
- `R`: reiniciar a posição

O protótipo inclui orla, mar, montanhas, prédios, palmeiras, um monumento no morro, trânsito simples, câmera de terceira pessoa e HUD de missão.
